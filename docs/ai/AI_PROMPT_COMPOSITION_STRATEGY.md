# AI Prompt Composition Strategy

## Objective

Create consistent prompts for Bodega6A AI operations.

## Prompt Structure

1. Agent instructions.
2. Project context.
3. User request.
4. Expected response format.
5. Validation requirements.

## Benefits

- Better reasoning.
- More relevant answers.
- Consistent outputs.
- Easier debugging.

## Goal

Allow the AI model to reason using Bodega6A-specific information.

# AI Permission Model

## Permission Categories

### Read Access

Allows:

- Project analysis.
- Documentation review.
- Repository understanding.

### Planning Access

Allows:

- Create proposals.
- Generate implementation plans.
- Analyze impact.

### Controlled Write Access

Allows:

- Prepare approved changes.
- Create controlled workflows.

### Critical Access

Requires:

- Additional approval.
- Audit record.
- Security validation.

## Goal

Keep AI capability aligned with safe operation.

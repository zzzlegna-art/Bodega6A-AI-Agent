# AI Technical Memory Rules

## Memory categories

### Architecture Memory

Stores:
- system decisions
- module relationships
- design choices

### Development Memory

Stores:
- solved problems
- implementation patterns
- previous fixes

### Decision Memory

Stores:
- why a solution was selected
- alternatives considered
- tradeoffs

## Principles

- Keep memory relevant.
- Avoid storing unnecessary information.
- Preserve traceability.

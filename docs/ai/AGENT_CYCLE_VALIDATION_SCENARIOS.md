# Agent Cycle Validation Scenarios

## Scenario 1 - Platform Analysis

Request:

Analyze a platform area.

Expected:

- Context retrieved.
- Relevant components identified.
- Technical explanation generated.

## Scenario 2 - Feature Planning

Request:

Plan a new feature.

Expected:

- Dependencies considered.
- Impact explained.
- Action plan prepared.

## Scenario 3 - Issue Investigation

Request:

Investigate a problem.

Expected:

- Related information found.
- Possible causes identified.
- Recommendations generated.

## Objective

Validate complete read-only agent behavior.

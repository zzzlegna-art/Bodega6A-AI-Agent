Connect external AI model provider.

Examples:
- GPT API.
- Claude API.

## Stage 2 - Agent Tools

Implement capabilities:

- Read repository.
- Search files.
- Analyze code.
- Modify files.
- Run validations.

Implement:

- Branch creation.
- Commit generation.
- Pull request workflow.

## Stage 4 - Controlled Automation

Enable:

- Request processing.
- Plan generation.
- Change preparation.
- Validation.

## Stage 5 - Production Readiness

Complete:

- Monitoring.
- Error handling.
- Security review.
- Deployment validation.

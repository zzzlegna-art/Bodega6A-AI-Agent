# Agent Execution Gate Model

## Purpose

Define the checkpoints required before an AI action can run.

## Gates

### Gate 1 - Understanding

Verify request interpretation.

### Gate 2 - Context

Verify required project information.

### Gate 3 - Permission

Verify allowed capabilities.

### Gate 4 - Risk

Evaluate possible impact.

### Gate 5 - Execution

Allow controlled operation.

### Gate 6 - Validation

Confirm result.

## Goal

Maintain safe automation.

# AI Change Proposal Workflow

## Objective

Define how the agent prepares changes before applying them.

## Flow

Request

↓

Analyze Existing Code

↓

Generate Proposed Change

↓

Review Impact

↓

Validate Security

↓

Request Approval

↓

Apply If Authorized

## Proposal Contents

- Objective.
- Affected files.
- Expected modifications.
- Risks.
- Validation steps.

## Goal

Make every AI-generated change understandable before execution.
